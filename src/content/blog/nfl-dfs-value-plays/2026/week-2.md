Week 1's board ran on DK's own published FPPG instead of this site's
model, disclosed at the time as a deliberate, temporary stopgap — with
zero 2026 games played yet, the model's "recent form" number was

Checked directly before switching back: DK's own FPPG turns out to be
just the single most recent game, full stop — no regression at all.
Ja'Marr Chase's Week 1 bust (3.2 points) is his entire FPPG number now;
Bijan Robinson's Week 1 boom (31.3) is his. This site's model reacts to
that same real result too, but blends it into a longer trailing window
instead of treating one game as the whole picture — which is the point
of a projection in the first place. Back to the model as the default
ranking basis, as planned from the start.

## FAQ

### Why did this board switch back to the model instead of DK's FPPG?

Because the reason for the Week 1 swap no longer applies. That stopgap
existed because this site's own model had zero current-season games to
build a "recent form" number from. A real Week 1 is now on file, and
the model's trailing-form calculation incorporates it — the trigger
condition for switching back, stated explicitly when the stopgap
started, has been met.

### Doesn't the model still have a very small current-season sample?

Yes, and that's disclosed, not hidden — one real game is a thin sample
for any method. The difference is what each method does with that one
game: DK's FPPG treats it as the entire number, no regression at all.
This site's model blends it into a longer trailing window that still
leans on prior-season history until more current-season games exist.
Neither is "solved" yet, but one of the two is designed not to overreact
to a single outlier.

### Why isn't every high-value name on this board a pick?

Because "value" only measures points against salary — it doesn't know
whether a player's current role actually supports getting those points.
This week's board is checked against real, team-reported depth-chart
data before any role gets described as a "starter"; when that data
doesn't back the number up (Antonio Williams above), this post says so
directly instead of quietly including the name anyway.

### Does an injury designation change the numbers?

Yes — a real "Questionable," "Doubtful," or "Out" status pulls a
player's projection down in this site's model, and an "Out" designation
excludes a player from this board outright regardless of ranking basis.
Any remaining designation is shown as a plain label so you can weigh it
yourself.

### When does this get updated before kickoff?

Whenever a salary, projection, or depth-chart change is significant
enough to matter. Check the "as of" line at the top of the post — it
always reflects the most recent real update, not just when this was
first published.
