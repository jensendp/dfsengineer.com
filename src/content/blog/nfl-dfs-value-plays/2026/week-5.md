## FAQ

### Why isn't every high-value name on this board a pick?

Because "value" only measures points against salary — it doesn't know
whether a player's current role actually supports getting those points.
This week's board is checked against real, team-reported depth-chart
data before any role gets described as a "starter"; when that data
doesn't back the number up, this post says so directly instead of
quietly including the name anyway.

### Does an injury designation change the numbers?

Yes — a real "Questionable," "Doubtful," or "Out" status pulls a
player's projection down in this site's model, and an "Out" or
"Doubtful" designation excludes a player from this board outright
regardless of ranking basis. Any remaining designation is shown as a
plain label so you can weigh it yourself.

### Why do some players show such a large gap against DK's own FPPG?

DK's FPPG is a simple recent-average number with its own real
limitations — it can lag a role change, overweight one big or one bad
recent game, or simply use a shorter window than this site's model.
Neither number is automatically "right"; a large gap is a real signal
worth investigating, not an error to explain away.

### When does this get updated before kickoff?

Whenever a salary, projection, or depth-chart change is significant
enough to matter. Check the "as of" line at the top of the post — it
always reflects the most recent real update, not just when this was
first published.
