## FAQ

### Why isn't every high-value name on this board a pick?

Because "value" only measures projected points against salary — it
doesn't know whether a player's current role actually supports getting
those points. This week's board is checked against real, team-reported
depth-chart data before any role gets described as a "starter" or
similar; when that data doesn't back the number up, this post says so
directly instead of quietly including the name anyway.

### Does an injury designation actually change the numbers?

Yes, directly. A real "Questionable," "Doubtful," or "Out" status on a
player pulls their projection down by a set amount before they show up
on this board at all — see James Conner above for a live example. It's
not hidden and it's not a footnote; it's already priced into the number
you're looking at.

### Are deep-bench backups filtered out of this board?

Yes. Any player whose only real recent history is three-plus seasons old,
or whose current team-reported depth-chart spot is clearly buried at
their position, gets capped to a replacement-level baseline instead of
carrying a stale or unsupported number forward. That's a real check
against this week's data, not an assumption.

### Does the matchup affect this week's rankings?

Mostly not, with one real exception. Most of this week's top values carry
a neutral matchup multiplier (1.0x) — the value is coming from the
salary-to-projection gap itself. Jacksonville's defense is the one clear
exception this week (1.61x), where the matchup itself is doing real work,
not just the price.

### When does this get updated before kickoff?

Whenever a salary, projection, or depth-chart change is significant
enough to matter. Check the "as of" line at the top of the post — it
always reflects the most recent real update, not just when this was
first published.
